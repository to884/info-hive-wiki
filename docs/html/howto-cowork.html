Cowork でローカルの wiki を使う

Windows 11 で Code 側に作った wiki を、Cowork のセッションから読みます。

Windows 側で wiki を準備する

Code タブに wiki を入れていなければ、Code タブの導入手順を実行します。

  1. 対象のローカルフォルダーを Code タブで開きます。
  2. 次のコマンドを送ります。
    /wiki:init
  3. 初期化の出力が "status": "ready" になったことを確かめます。

検証中、Cowork のクラウドで初期化すると、検索モデルの取得が HTTP 403 で止まりました。上の手順で確認できる状態は Windows 側の wiki です。

Cowork 側にも Wiki を追加する

  1. チャットと Cowork の画面で「プラグイン」を開きます。
  2. 「追加」から「マーケットプレイスを追加」を選びます。
  3. 「リポジトリから追加」で to884/info-hive-marketplace を同期します。
  4. 「Wiki」の詳細を開いて「追加」を押します。
  5. 提供元を確認し、ローカル MCP サーバーの確認で「続ける」を押します。

フォルダーを接続して wiki を確かめる

クラウドで動くセッションは、Claude が使うファイルを Anthropic のサーバーで処理します。利用できる資料とフォルダーを選んでから、表示された許可の内容を確認します。

  1. 「新規作成」を開きます。
  2. 「プロジェクトまたはフォルダー」の「フォルダを追加」を選びます。
  3. Windows 側で初期化したフォルダーを選びます。
  4. 表示されたフォルダーアクセスの確認で、必要な範囲を許可します。
  5. 「wiki の MCP のツール `stats` を呼んで、結果をそのまま見せてください」と送ります。

ツールの結果で Windows 側の wiki のパスとページ数が表示されることを確かめます。空の wiki ならページ数は 0 です。
