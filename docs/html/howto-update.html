wiki プラグインを更新する

Claude デスクトップアプリの Code タブで、info-hive の配布情報と Wiki の更新を確認します。

マーケットプレイスを更新する

  1. ディレクトリを開きます。
  2. 「プラグイン」の「Code」を選びます。
  3. 「info-hive」のメニューを開きます。
  4. 「アップデートを確認」を選びます。
  5. 「マーケットプレイスを更新しました。」と表示されることを確かめます。

Wiki の更新を確認する

  1. 設定の「プラグイン」を開きます。
  2. 「Wiki」のメニューを開きます。
  3. 「アップデートを確認」を選びます。
  4. Code のディレクトリで Wiki の詳細を開き、導入済みの版を確認します。

「前回のリリース以降、変更はありません。」と表示されたら、同じ版を使えます。

既存の wiki を確認する

新しい版が入ったら、既存の wiki を開き、wiki の規約と検索環境をアップグレードする手順に進みます。
