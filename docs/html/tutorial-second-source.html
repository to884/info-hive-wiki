醤油を取り込み、wiki を点検する

味噌を取り込んだ練習用 wiki に醤油の資料を追加します。「麹」のページで味噌と醤油のつながりを確認し、最後に wiki を点検します。

1. 醤油の資料を取り込む

  1. 次の資料をメモ帳にコピーします。
    # 醤油

醤油は、大豆と小麦を主な原料にした、日本の発酵調味料である。

蒸した大豆と、炒って砕いた小麦を混ぜ、麹菌を育てて麹を作る。この麹に食塩水を加えて「もろみ」にし、数か月から 1 年ほどかけて、発酵させ、熟成させる。熟成したもろみを搾った液体が、醤油になる。

味噌と同じく、原料に大豆、麹、塩を使う。味噌は麹と大豆を固まりのまま熟成させるが、醤油はもろみを搾って液体にする。

日本農林規格（JAS）は、醤油を、濃口、淡口、たまり、再仕込み、白の 5 種類に分けている。
  2. 「名前を付けて保存」で %USERPROFILE%\info-hive-practice\raw\醤油.md に保存します。「すべてのファイル」と UTF-8 を選びます。
  3. 前のチュートリアルと同じ練習用フォルダーを開いた Code タブで、次のコマンドを送ります。
    /wiki:ingest raw/醤油.md
  4. 要点を示されたら「『麹』のページに、醤油のことも書き足してください」と返します。
  5. 提案された変更を確認し、適用を承認します。

取り込みの目印

wiki/sources/醤油.md ができ、索引に醤油の要約へのリンクが加わります。wiki/log.md には取り込みの記録が 1 件加わります。

2. 資料どうしのつながりを見る

  1. 次のコマンドを送ります。
    /wiki:browse
  2. 返答の「Index · プロジェクト」のカードで「開く」を押します。
  3. ブラウザーペインの「Index」を開きます。
  4. 一覧に味噌と醤油の要約があることを確かめます。
  5. 「麹」のページを開きます。

「麹」のページの被リンクに、味噌と醤油の要約があることを確かめます。

ブラウザーペインが開かなければ、Code タブに、返答にある http://127.0.0.1: で始まる URL をペインで開くよう頼みます。

「麹」に醤油の記述がなければ、そのページに醤油のことを書き足すようもう一度頼みます。

3. wiki を点検する

  1. 次のコマンドを送ります。
    /wiki:lint
  2. 点検のツール呼び出しを開きます。
  3. 調べたページが 2 件以上で、孤立ページ、リンク切れ、読み込みエラーがないことを確かめます。

MCP の出力では total_pages がページ数です。orphans、broken_links、read_errors が空かを見ます。CLI の出力では「調べたページ数」と同じ 3 種類の指摘の有無を見ます。

練習では tags の空欄や、原本より強い表現を指摘されることがあります。指摘を確認したら、次へ進めます。修正する場合は、提案された差分を確認してから承認します。
