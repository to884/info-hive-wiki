wiki の用語

操作の案内や回答に出てくる用語を説明します。

保存場所

wiki
エージェントが整理した Markdown のページを置く場所です。
raw
取り込む資料とその写しを置く場所です。
SCHEMA.md
ページの種類、タグ、取り込みの規約を記したファイルです。
プロジェクトスコープ
開いているフォルダーに置く wiki です。
ユーザースコープ
複数の作業フォルダーから使う個人の wiki（ユーザー wiki）を指します。

ページと点検

索引
wiki のページを探すための一覧です。通常は wiki/index.md から開きます。
wikilink
[[味噌]] のようにページを指すリンクです。
被リンク
今開いているページを指している、ほかのページからのリンクです。
シンセシス
複数のページの内容をまとめたり、比較したりしたページです。
lint
リンク切れや孤立などの構造を調べ、内容の古さや矛盾も確認する操作です。

検索と回答

MCP
Claude Code が wiki の検索、点検、統計などのツールを呼ぶための仕組みです。
埋め込み
文の内容を数の並びで表し、近い内容を検索するために使います。
信頼度
回答が wiki の出典でどれだけ裏付けられるかを、高・中・低で示す値です。
