wiki を点検し、グラフを更新する

すでに作ってある wiki が対象です。複数の wiki を使っている場合は、対象の wiki のパスをコマンドと一緒に伝えます。

リンクや記事の内容を点検する

資料を何件か取り込んだあとや、記事をまとめて移動・改名したあとに /wiki:lint を使います。 継続して資料を取り込む wiki では、週に 1 回など、まとめて指摘を確認できる間隔で実行します。

  1. Claude Code では /wiki:lint、Codex では $wiki:info-hive lint を送ります。
  2. リンク切れや孤立ページなどの指摘と、記事の内容に関する修正案を確認します。
  3. 必要な修正を承認します。修正したあと、同じコマンドで該当する指摘が解消したかを確認します。

記事の変更をグラフに反映する

手元の Markdown を直接使う wiki に graph/ontology.yaml があれば、初めてグラフを作るときに /wiki:graph extract を使います。 資料を取り込んだり、記事を追加・削除・改名・編集したりしたあとも、グラフの更新が済んでいなければ、関係を調べる前に実行します。

公開版を使う wiki では、記事を保存する手順の中でグラフも更新します。

  1. 型付きの関係（graph.relationships）やオントロジーを編集した場合は、先に上の点検を行い、グラフの指摘を確認します。
  2. Claude Code では /wiki:graph extract、Codex では $wiki:info-hive graph extract を送ります。
  3. 抽出したノードとエッジの件数が報告され、graph/graph.sqlite が作成または更新されたことを確かめます。

graph/ontology.yaml がない wiki でグラフを使い始める場合は、wiki をアップグレードする手順に進みます。
