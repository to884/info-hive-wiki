Web ページを wiki に取り込む

初期化したプロジェクト wiki に Web ページを追加し、取り込まれた原本と要約を確かめます。

ページの URL を渡す

  1. 対象の wiki を開いた Code タブで URL を指定します。
    /wiki:ingest https://www.iana.org/help/example-domains
  2. wiki:web-raw を使う場合は、原本の取得と検査が終わるのを待ちます。
  3. 要点を確認します。
  4. 差分が示されたら、取り込む変更を承認します。

翻訳や取得の確認を求められた場合

翻訳の警告が残る場合は、指摘された箇所と理由を確認します。そのまま取り込むときは、理由をログに残す案を承認します。completed: true が出たら原本の検査は完了です。

ブラウザーでの取得を求められたら、対象ページを普段の Chrome または Edge で開きます。接続画面で対象のタブだけを選びます。接続方式では Node.js 20 以上と npm が必要です。

保存されたファイルを確認する

取り込み後は、raw/ に原本があり、wiki/sources/ にその要約があることを確かめます。取り込みの記録は wiki/log.md に加わります。
