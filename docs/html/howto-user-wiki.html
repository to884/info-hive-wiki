複数の作業フォルダーから使う wiki を作る

複数の作業フォルダーから使える wiki を、Windows のユーザーごとに 1 つ作ります。Code タブの新しいセッションには、その wiki の場所を伝えます。

ユーザー wiki を初期化する

  1. Code タブで新しいローカルセッションを開きます。
  2. 次のコマンドを送ります。
    /wiki:init --user
  3. 既定の場所で進めます。
  4. 初期化したツールの出力で "status": "ready" を確かめます。

既定の場所は %USERPROFILE%\info-hive\wiki\ と %USERPROFILE%\info-hive\raw\ です。

新しいセッションが wiki の場所を知るようにする

  1. グローバルな指示の追記案を読みます。
  2. 案に実際のユーザー wiki の場所があることを確かめます。
  3. 提案を承認します。
  4. %USERPROFILE%\.claude\CLAUDE.md に案が入ったことを確かめます。

コマンドを手入力して検索する場合は、検索例の --wiki wiki/ を実際のユーザー wiki の絶対パスに変えます。
