起動や接続の障害を調べる

Code タブで wiki が接続されないときや、初期化の実行環境が準備できないときに使います。

コマンド一覧が出ないとき

PowerShell で python --version を実行します。Microsoft Store の案内が出た場合は、Python 3.12 を入れる手順に戻ります。

版が表示されたら、アプリを起動し直す手順を行い、/wiki:help をもう一度送ります。

wiki に再接続する

  1. Code タブで /mcp を送ります。
    /mcp
  2. 一覧の「wiki」を開きます。
  3. 「再接続」を押します。
  4. 接続済みに戻り、wiki のツールが表示されることを確かめます。

Windows で起動の診断を実行する

新しい PowerShell で次を実行します。0.39.1 は導入済みの版に合わせます。最後の行が 0 なら起動診断は成功です。

$version = '0.39.1'
$launcher = Join-Path $env:USERPROFILE ".claude\plugins\cache\info-hive\wiki\$version\skills\info-hive\scripts\wiki_mcp_launch.py"
uv run --quiet --script $launcher --ensure
$LASTEXITCODE

診断が失敗した場合は、開始時刻、終了コード、表示されたエラー、使用した版を控えます。

エクスプローラーで %LOCALAPPDATA%\info-hive\logs\ を開きます。server.log や launch.log があれば、実行時刻に近い行を確認します。

DLL または証明書のエラーを確認する

Visual C++ ランタイムの不足が出た場合、Windows x64 では次を実行します。

winget install --id Microsoft.VCRedist.2015+.x64 -e --source winget

証明書の検証で失敗した場合は、組織の証明書を使う手順を確認します。

初期化で "status": "ready" が出ていない場合は、原因を解消してから /wiki:init をもう一度送ります。
