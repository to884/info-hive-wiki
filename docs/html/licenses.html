同梱したサードパーティのパッケージ

wiki_pages.py は、同梱の Markdown 解析器で本文の wikilink を検出します。lint と統計は、別途パッケージをインストールせずに使えます。閲覧（browse）でも同じ解析器を使い、コードと本文を見分ける規則を 1 か所にまとめています（ADR-0010 の決定の 1）。

パッケージ 版 取得元の wheel SHA-256 ライセンス
markdown-it-py（markdown_it/） 3.0.0 markdown_it_py-3.0.0-py3-none-any.whl 355216845c60bd96232cd8d8c40e8f9765cc86f46880e43a8fd22dc1a1a8cab1 MIT（licenses/markdown-it-py.LICENSE。移植元の markdown-it は licenses/markdown-it.LICENSE）
mdurl（mdurl/） 0.1.2 mdurl-0.1.2-py3-none-any.whl 84008a41e51615a49fc9966191ff91509e3c40b939176e643fd50a5c2196b8f8 MIT（licenses/mdurl.LICENSE）
  • どちらも PyPI の wheel をそのまま展開したもので、中身は書き換えていません。2026年11月9日に、SHA-256 が PyPI の公表値と一致することを確認しました。
  • markdown-it-py は mdurl に依存します。どちらも純粋な Python で、ほかの依存はありません。
  • wiki_pages.py は、このディレクトリを sys.path の先頭に追加してから読み込みます。別の場所の markdown_it や mdurl が先に読み込まれていても、同梱したものに替えます。読み込んだものが同梱したもので、版が MARKDOWN_IT_VERSION と MDURL_VERSION と同じことを確かめ、違えば止まります。

版を上げるとき

  1. 新しい版の wheel を取得し、SHA-256 を PyPI の公表値と照らします。
  2. markdown_it/ と mdurl/ を入れ替え、ライセンスの文書も入れ替えます。
  3. wiki_pages.py の MARKDOWN_IT_VERSION と MDURL_VERSION を上げます。読み込んだ版がこの定数と違えば止まります。MCP サーバーの版（wiki_mcp_common.code_version）は _vendor/ の中身も含めて計算するので、動いているサーバーは入れ替わります。検索のパースキャッシュは、解析器の名前（PARSER_ID）が変わるので作り直されます。
  4. 開発リポジトリの tests/wiki/test_page_set.py の例が成功することを確かめます。閲覧の中核も同じ版にそろえます。

閲覧（browse）の画面の資産

閲覧画面の表示と静的サイトの書き出しに使うファイルです。閲覧画面は、ページの CSP（style-src 'self'; script-src 'self'）に従って、CSS と JavaScript を外部ファイルとして読み込みます。

ファイル 中身
style.css 閲覧の画面の独自の CSS
app.js ナビゲーションを組み立て、データの世代を確かめるスクリプト
fluent2.css Fluent 2 の Web 版のデザインを、React を使わない CSS で再現したもの（非公式）。下の「同梱した Fluent 2 の CSS」を参照
figures.js 本文の Mermaid のフェンスを図として描くスクリプト（親の側）。サーバー方式でのみ動きます（ADR-0030）。
mermaid-frame.html、mermaid-frame.js Mermaid を動かす sandbox の枠の文書と、その中のスクリプト。サーバーがトークンのない /_frame/<版>/ から配り、静的サイトには含めません。
mermaid.tiny.js Mermaid の束。下の「同梱した Mermaid」を参照
render-pele.mjs 静的の書き出し時に Node.js 20 以上で図を読み、明暗 2 配色の SVG を生成する
pele.mjs 静的の書き出し時にだけ使う Pele の束。下の「同梱した Pele」を参照
licenses/ 同梱したファイルのライセンスの文書。閲覧の出力には含めません。
