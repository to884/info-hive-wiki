wiki コマンドのリファレンス

wiki 0.39.1 の Claude Code 向けコマンド 12 本の書式、引数、結果を確認できます。初期化とヘルプ以外は、対象の wiki に SCHEMA.md が必要です。

/wiki:init　wiki を初期化する

引数を省略するとプロジェクトの wiki を作ります。--user はユーザースコープで、--wiki-dir と --raw-dir はディレクトリ名を指定します。完了時は実行環境に "status": "ready" が出ます。

/wiki:init [--user] [--wiki-dir <name>] [--raw-dir <name>]

例 /wiki:init --user

ユーザー wiki の初期化と指示の設定

/wiki:ingest　資料を取り込む

資料を指定すると、原本と要約を準備します。提案された変更を確認し、承認すると wiki に反映されます。

/wiki:ingest <ソースのパス、URL、session、または説明>

取り込める形式

  • Markdown・テキスト（.md、.txt）。メモや文字起こしをファイルのパスで指定します。例 /wiki:ingest raw/味噌.md
  • PDF（.pdf）。例 /wiki:ingest raw/論文.pdf。通常の取り込みでは PDF の文字の層を読みます。Claude Code で rag@info-hive の OCR が有効なら、スキャンのページも文字にできます。
  • Web ページ（HTTP・HTTPS の URL）。本文を Markdown に変換して取り込みます。例 /wiki:ingest https://example.com/article。Web ページの取り込み方も参照できます。
  • YouTube 動画の字幕。ログインや年齢確認なしで視聴できる、字幕つきの動画を 1 本指定します。例 /wiki:ingest https://www.youtube.com/watch?v=<動画のID>
  • Claude Code・Codex の会話。現在の会話には session、同じアプリの別の会話には session:<ID> を使います。Claude Code の記録ファイルは session:<パス> または .jsonl のパスで指定できます。Claude Code から Codex の会話を取り込むときは codex:<ID> を指定します。例 /wiki:ingest session、$wiki:info-hive ingest session

ローカルのフォルダーも資料として指定できます。ファイルにしていないメモは、本文をチャットに貼り付けて取り込みを依頼できます。

/wiki:query　出典付きの答えを得る

質問を指定すると、wiki のページをもとに、出典と確信度を添えて答えます。答えの一部で根拠が足りない場合は、どこが足りないかを伝えます。必要に応じて検索します。

/wiki:query <質問>

例 /wiki:query 味噌の原料は？

索引と検索の仕組み

/wiki:lint　構造と内容を点検する

リンク切れ、孤立ページ、読み込みエラーなどを調べます。記述の矛盾や不足も確認します。--suggest-pages を付けると独立ページの候補も示します。

/wiki:lint [--suggest-pages]

例 /wiki:lint

点検結果の見方

/wiki:stats　wiki の統計を表示する

引数は不要です。ページ数、リンク密度、索引の構成や検索索引の状態を調べます。ページがまだなければ、ページ数は 0 になります。

/wiki:stats

例 /wiki:stats

/wiki:graph　型付きの関係を調べる

extract はグラフを生成し、lint は型付き関係を点検します。neighbors は近くのノード、edges は関係、path は経路、facts は対象についての事実を調べます。edges の --predicate は関係の種類、path の --max-depth はたどる関係の最大数を指定します。

/wiki:graph extract | lint | neighbors --node <id> | edges --subject <id> | path --from <id> --to <id> | facts --about <id>

例 /wiki:graph lint

/wiki:browse　wiki をブラウザーで開く

引数を省略すると閲覧画面を開きます。ページのスラッグを指定すると、そのページを開きます。--stop で閲覧用サーバーを止めます。

/wiki:browse [slug] | --stop

例 /wiki:browse

Index と被リンクの見方

/wiki:overview　ページの概要図を作る

対象ページの概要を本文と別に保存します。--refresh は概要を作り直します。--status はページごとの概要の状態を一覧にします。--remove は指定したページの概要を削除します。

/wiki:overview <page> [--refresh] | --status | --remove <page>

例 /wiki:overview --status

/wiki:upgrade　既存の wiki をアップグレードする

引数を省略すると現在のプロジェクトが対象になります。--user はユーザー wiki を選びます。--wiki-dir と --raw-dir は現在の保存場所を指定します。過去に使用した原本フォルダーは --previous-raw-root で登録でき、複数ある場合は繰り返し指定できます。

/wiki:upgrade [--user] [--wiki-dir <path>] [--raw-dir <path>] [--previous-raw-root <path> ...]

例 /wiki:upgrade

規約の差分と実行環境の確認

/wiki:learn　作業の経験を記録する

成果物や検証済みの経験を指定します。経験から得た教訓をまとめ、保存の候補を示します。

/wiki:learn <タスクの成果物、または経験の記録>

例 /wiki:learn この取り込みで検証した手順を記録してください

/wiki:evolve　スキルの改善案を評価する

スキルと改善の目的を指定します。history は履歴、show <実験 ID> は詳細を表示します。apply <実験 ID> は評価と承認を済ませた案を適用し、rollback <実験 ID> はその変更を元に戻します。

/wiki:evolve <スキルと改善の目的 | history | show/apply/rollback 実験 ID>

例 /wiki:evolve history

/wiki:help　アプリでコマンドの一覧を出す

引数を省略するとコマンドが一覧になります。コマンド名を指定すると、そのコマンドのヘルプが表示されます。操作に必要な引数と手順は、この HTML から確認できます。

/wiki:help [command]

例 /wiki:help
