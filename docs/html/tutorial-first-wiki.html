はじめての wiki を作る

味噌の資料を 1 件取り込み、味噌の原料を質問します。答えに出典が付くことを確かめます。

環境
Windows 11、Claude デスクトップアプリの Code タブ
準備
Git for Windows、uv、Python 3.12、Microsoft Visual C++ 再頒布可能パッケージ、wiki@info-hive
検証版
Claude Desktop 6.6395.0.0、wiki 0.39.1

Code タブで /wiki:help を送って、一覧に /wiki:init が表示されたら、この練習に進めます。準備が必要なときは、Code タブに wiki を入れる手順を開きます。

1. 練習用フォルダーを開く

  1. エクスプローラーで %USERPROFILE% を開きます。
  2. info-hive-practice という空のフォルダーを作ります。
  3. Claude デスクトップアプリの Code タブを開きます。
  4. 「このコンピューター」で info-hive-practice を選びます。
  5. 「このワークスペースを信頼しますか？」と聞かれたら、練習用フォルダーのアクセスを承認します。

2. wiki を作る

初回は multilingual-e5-small（約 250 MB）を %USERPROFILE%\.cache\info-hive\fastembed\ に取得します。数分かかることがあります。

  1. Code タブの入力欄から次のコマンドを送ります。 
    /wiki:init
  2. 初期化の設定を聞かれたら、次の内容を伝えます。「後回し」が選択肢になければ、自由入力で答えます。
    プロジェクトの wiki にしてください。場所は、このフォルダーの wiki/ と raw/ です。モデルのキャッシュは既定の場所にしてください。グラフ層は後回しにします。エージェントとの連携は、このフォルダーの CLAUDE.md に追記してください。
  3. init_wiki.py を実行したツール呼び出しを開き、出力の "status": "ready" を確かめます。
  4. 規約の変更を聞かれたら、練習では「変更しません」と答えます。
  5. CLAUDE.md の案を示されたら、標準案を承認します。

初期化すると、wiki/SCHEMA.md ができます。エージェントはこのファイルを読み、ページの名前やタグ、取り込み手順など、この wiki の規約に沿って作業します。

自分の wiki では、初期化後にこのファイルをテキストエディターで開き、規約を編集できます。たとえば既存の「タグの体系」の節に「会議メモ」を追加し、どの資料の要約に付けるかを書きます。保存したら、新しいチャットでその wiki に会議メモを取り込み、意図したタグが付くことを確かめます。

編集するときは、ファイル名を SCHEMA.md のままにし、アップグレードの目印となる ## Retrieval などの英語の見出しも保ちます。

エラーで止まったら、検索環境の障害対処を確認します。

3. 味噌の資料を取り込む

  1. 次の練習用資料をメモ帳にコピーします。 
    # 味噌

味噌は、大豆を主な原料にした、日本の発酵調味料である。

蒸すか煮るかしてやわらかくした大豆をつぶし、麹と塩を混ぜて仕込む。これを数か月から数年おいて、発酵させ、熟成させる。

麹は、米、麦、大豆などの穀物に麹菌を育てたものである。どの麹を使うかで、米味噌、麦味噌、豆味噌に分けられる。

熟成の期間が長いほど、色は濃くなる。塩の量と麹の量の割合で、味が甘口にも辛口にもなる。
  2. 「名前を付けて保存」で %USERPROFILE%\info-hive-practice\raw\味噌.md に保存します。「ファイルの種類」は「すべてのファイル」、「エンコード」は UTF-8 を選びます。
  3. Code タブの入力欄から次のコマンドを送ります。 
    /wiki:ingest raw/味噌.md
  4. 要点を示されたら「『麹』のページを作ってください」と返します。
  5. 作成するページと変更の一覧を確認し、適用を承認します。

取り込みの目印

エクスプローラーで練習用フォルダーの wiki を開きます。

  • wiki/sources/味噌.md ができています。
  • wiki/index.md に [[味噌 で始まるリンクが加わります。ほかのページの行が増えることもあります。
  • wiki/log.md の末尾に今日の日付の ## [日付] ingest | 味噌 が加わります。

原本が見つからないときは、エクスプローラーでファイル名拡張子を表示し、練習用フォルダーの raw に 味噌.md があることを確かめます。

手元の資料を取り込むときは、raw/ の外にあるファイルもパスで指定できます。たとえば「C:/資料/会議メモ.md をこのプロジェクトの wiki に取り込んで」と頼みます。この例では、練習用フォルダー直下の raw/ に資料のコピーができます。

4. 味噌の原料を質問する

  1. Code タブの入力欄から次のコマンドを送ります。 
    /wiki:query 味噌の原料は？
  2. 答えに [[味噌]] のような出典が少なくとも 1 つあることを確かめます。
  3. 答えの末尾に「信頼度（confidence）」の行があることを確かめます。

出典がないときは、取り込みの目印を確認します。練習用フォルダーは次のチュートリアルでも使います。
