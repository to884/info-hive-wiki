移植元の記録

info-hive は、praneybehl/llm-wiki-plugin（MIT ライセンス、作者 Praney Behl）を日本語向けに移植したものである。移植元の履歴は取り込まず、ファイルをコピーして独立させた（移植計画の方針 A）。

起点のコミットに、手元のフォーク（to884/llm-wiki-plugin）にあった未コミットの日本語訳 94 ファイルを重ねた状態を取り込んだ。訳を入れた各ファイルの SHA-256 は 開発用のリポジトリの docs/upstream/translation-hashes.txt に残してある。

取り込み後の主な変更

  • プラグイン名を wiki、マーケットプレイス名とスキル名を info-hive にした。マーケットプレイスの定義は、別のリポジトリ to884/info-hive-marketplace に置く。コマンドは commands/ の直下に移し、/wiki:query の形で起動する。
  • スキルのディレクトリを skills/llm-wiki/ から skills/info-hive/ に改名した。
  • 判定レイヤーの環境変数を LLM_WIKI_DECISIONS* から INFO_HIVE_DECISIONS* に、モデルのキャッシュを ~/.cache/llm-wiki/ から ~/.cache/info-hive/ に変えた。

日本語への対応の内容は 移植計画 と CHANGELOG.md にまとめる。移植元の v0.1.0 から v4.0.1 までの変更履歴の日本語訳は docs/upstream-changelog.md に残している。

移植元の修正を取り込む手順

移植元に役立つ修正が入ったら、必要なものだけを取り込む。履歴を共有していないので、パスの違い（skills/llm-wiki/ と skills/info-hive/、commands/wiki/ と commands/）に注意する。

git remote add upstream https://github.com/praneybehl/llm-wiki-plugin.git   # 初回だけ
git fetch upstream
git log --oneline 2d24ccf..upstream/main
git cherry-pick <コミット>   # 衝突したら、パスを読み替えて手で直す
