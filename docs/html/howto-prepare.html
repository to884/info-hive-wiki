事前準備を確認する

wiki を入れる前に、必要なコマンドと通信の設定を確認します。

ソフトウェアを確認する

新しい PowerShell で次を実行します。python --version が Microsoft Store の案内を出す場合は、Python 3.12 を導入する手順に進みます。

git --version
uv --version
python --version

DLL を読み込めない場合は、Visual C++ ランタイムの確認に進みます。

uv を入れる

Windows

  1. PowerShell で Astral のインストーラーをダウンロードします。
    Invoke-WebRequest -UseBasicParsing -Uri 'https://astral.sh/uv/install.ps1' -OutFile "$env:TEMP\uv-install.ps1"
  2. ダウンロードしたスクリプトを実行します。
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\uv-install.ps1"
  3. 新しい PowerShell を開きます。
  4. uv --version でバージョンが表示されることを確かめます。

macOS・Linux

  1. ターミナルで Astral のインストーラーを実行します。
    curl -LsSf https://astral.sh/uv/install.sh | sh
  2. 新しいターミナルを開きます。
  3. uv --version でバージョンが表示されることを確かめます。

組織の証明書を使う

社内プロキシで TLS の検証に失敗する場合は、組織が配布した証明書が Windows の証明書ストアにあるか、管理者に確認します。

  1. 次を実行し、uv が UV_SYSTEM_CERTS に対応することを確認します。
    uv sync --help | Select-String "UV_SYSTEM_CERTS"
  2. 対応していれば、Windows のユーザー環境変数を設定します。
    [Environment]::SetEnvironmentVariable('UV_SYSTEM_CERTS', 'true', 'User')
  3. Claude デスクトップアプリを通知領域から終了します。
  4. Claude デスクトップアプリを起動し直します。

新しい PowerShell で $env:UV_SYSTEM_CERTS が true と表示されることを確認します。
