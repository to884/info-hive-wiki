Code タブに wiki を入れる

Windows 11 の x64 PC で、Claude デスクトップアプリの Code タブに wiki を導入します。

Windows 11 の VM で、Claude 5.11492.5 に wiki 0.39.1 を導入できることを確認しました。手順に載せた画面の表記は Claude 6.6395 で確認しています。

Claude デスクトップアプリを用意する

Claude にサインイン済みなら、「必要なソフトウェアを入れる」へ進みます。

  1. Anthropic の公式パッケージ Claude MSIX（Windows x64）をダウンロードします。
  2. スタートメニューの「Windows PowerShell」を「管理者として実行」で開きます。
  3. 次のコマンドの「ダウンロードした MSIX のパス」を、ファイルのフルパスに置き換えて実行します。
    Add-AppxPackage -Path "ダウンロードした MSIX のパス"

スタートメニューから Claude を開いてサインインします。

1. 必要なソフトウェアを入れる

PowerShell を開いて、次の操作を順に行います。

  1. Git for Windows を入れます。
    winget install --id Git.Git -e --source winget
  2. Astral の uv インストーラーをダウンロードします。
    Invoke-WebRequest -UseBasicParsing -Uri 'https://astral.sh/uv/install.ps1' -OutFile "$env:TEMP\uv-install.ps1"
  3. ダウンロードしたスクリプトを実行します。
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\uv-install.ps1"
  4. Python 3.12 を入れます。
    winget install --id Python.Python.3.12 -e --source winget
  5. Microsoft Visual C++ 再頒布可能パッケージを入れます。
    winget install --id Microsoft.VCRedist.2015+.x64 -e --source winget

winget で配布元やパッケージの規約が表示された場合は、内容を確認し、同意できれば Y を入力して続けます。

社内の証明書で通信を検査する環境では、事前準備の証明書設定を確認します。

2. 新しい環境でアプリを起動する

  1. PowerShell を閉じます。
  2. 通知領域の Claude アイコンからアプリを終了します。
  3. Claude デスクトップアプリを開きます。
  4. 新しい PowerShell を開きます。
  5. 各コマンドを実行し、それぞれ版が出ることを確かめます。
    git --version
uv --version
python --version

3. マーケットプレイスを追加する

Code タブで「プラグイン」を開きます。以前の版では「カスタマイズ」から「プラグイン」を開きます。

  1. 「追加」を押します。
  2. 「マーケットプレイスを追加」を選びます。
  3. 「リポジトリから追加」を選びます。
  4. 「URL」欄に to884/info-hive-marketplace を入力します。
  5. 「同期」を押します。

4. Wiki を追加する

「探索」を押してディレクトリを開きます。

  1. 「プラグイン」の「Code」を選びます。
  2. 「info-hive」の一覧を表示します。
  3. 「Wiki」の「+」を押します。
  4. ローカル MCP サーバーの確認画面で「続ける」を選びます。
  5. 設定画面が出たら、既定値で進めます。

設定の「プラグイン」で Wiki が「ローカルにインストール済み」と表示されることを確かめます。

5. コマンドの一覧を表示する

  1. 通知領域から Claude デスクトップアプリを終了します。
  2. Claude デスクトップアプリを起動します。
  3. 新しい Code セッションで空のフォルダーを開きます。練習用フォルダーを開く手順も使えます。
  4. 次のコマンドを送ります。
    /wiki:help
  5. /wiki:overview を含む 12 本のコマンドが表示されることを確かめます。

コマンド一覧が出なければ、コマンド一覧が出ないときの手順に進みます。

MCP サーバーの依存がそろったかを確認する場合は、Windows で起動の診断を実行するの手順を使います。
