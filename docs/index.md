# info-hive のドキュメント

HTML マニュアルは、ローカル HTTP サーバー経由で開きます。
サーバーの起動方法とブラウザーで開く URL は、[README の「ドキュメント」](../README.md#ドキュメント)を参照してください。

## できること

```mermaid
flowchart LR
    wiki["info-hive"] --> ingest["資料を取り込む<br/>PDF・Web・会話"]

    wiki --> maintain["wiki を保つ<br/>点検・更新・経験の記録"]
```
