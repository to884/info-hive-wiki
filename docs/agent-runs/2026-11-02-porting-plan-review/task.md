3. 段階の順序と依存: P0〜P6 の順序と依存関係に無理がないか。
4. 完了の判定とリスク: 判定できない条件、足りないリスク。
5. 方針 A〜J への意見。承認待ちの 4 項目（7 節）と、作者が質問への回答で決めた方針 C〜J のどちらも批判の対象にしてよい。反対するときは、代わりの案と理由を示す。
