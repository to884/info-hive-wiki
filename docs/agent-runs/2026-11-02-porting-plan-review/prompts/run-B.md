## 最終メッセージの形式

Markdown で、次の見出しをこの順に置く。

1. `## 結論`：タスクへの答え
2. `## 根拠`：結論を支える事実と推論
3. `## 検討した代替案`：採らなかった案と、採らなかった理由
4. `## 前提と不確実性`：依存している仮定、確かめられなかったこと、作者の判断が要ること
5. `## 参照`：読んだファイルと文書
