# 文字コード

文字コードは、文字をコンピューターで扱うためにバイトの並びへ対応させる規則である。書いたときと読むときで違う文字コードを使うと、文字が意味のない記号に置き換わる文字化けが起きる。

## Shift_JIS と CP932

Shift_JIS は、日本語の文字を 1 バイトまたは 2 バイトで表す文字コードで、古くから Windows や携帯電話で使われてきた。Windows が実際に使うのは、Shift_JIS に機種依存文字などを加えた CP932 である。「①」や「髙」のような文字は CP932 にはあるが、本来の Shift_JIS にはない。

## UTF-8

UTF-8 は、Unicode のすべての文字を 1〜4 バイトで表す文字コードである。日本語の文字の多くは 3 バイトになる。現在のウェブやプログラミングでは UTF-8 が標準になっている。

## BOM

BOM（byte order mark）は、ファイルの先頭に置いて文字コードを示す印である。UTF-8 の BOM は EF BB BF の 3 バイトになる。Excel は BOM の付いた CSV を UTF-8 として開くが、BOM がないと CP932 として読んで文字化けさせる。一方、BOM を想定していないプログラムは、先頭の 3 バイトを余計な文字として読んでしまう。
